# ハルシオン号 検分録 — The Halcyon Inquest

『Return of the Obra Dinn』に着想を得た、スマホ向けの1ビット推理アドベンチャー（ブラウザで動作）。

天保八年（1837年）、無人のまま長崎沖に流れ着いた英国商船ハルシオン号。
死者の最期を映す懐中時計を骸にかざし、乗員十名の **名前・死因・下手人** を突き止めて検分帳に記す。

## 遊び方

- `index.html` をブラウザで開くだけ（ビルド不要・外部依存なし。`file://` でも動作）。
- スマホで遊ぶ場合は静的ホスティング（GitHub Pages など）に置くか、`npx serve .` で配信。

1. 船内図で「!」の付いた場所をタップ → 死の直前の「音声」を聞く
2. 静止した死の瞬間をドラッグ／ピンチで見回し、人物をタップ
3. 検分帳で集合画の人物に名前・運命・下手人を記す
4. 正しい運命が **3人揃うごとに確定** する（どれが正解かは教えられない）
5. 骸を検分するたびに、ひとつ前の死の在りかが分かる（時間を遡る構成）

## 構成

| ファイル | 内容 |
| --- | --- |
| `js/render.js` | グレースケール描画 → 8×8 Bayer ディザで2色化。手続き型の人物（関節ポーズ・服装・小道具） |
| `js/scenes.js` | 各章の背景と静止場面、集合画、船内図 |
| `js/data.js` | 乗員名簿・集合画の人物・死因・章の台詞・正解 |
| `js/main.js` | 画面遷移、パン／ズーム、検分帳、3人確定ロジック、localStorage 保存 |
| `js/audio.js` | WebAudio による効果音（音声ファイルなし） |

配色は設定から4種（羊皮紙／マッキントッシュ／琥珀／深海）を切り替え可能。
